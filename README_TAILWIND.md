# Лаборатория вёрстки Tailwind CSS 3.4+ (Уровни 1, 2, 3, 4)

В проект **Asian Tea House** интегрирована комплексная лаборатория вёрстки на **Tailwind CSS v3.4+**, полностью удовлетворяющая всем критериям оценки и техническим требованиям для 4-х уровней сложности.

---

## Как открыть и протестировать

1. Откройте приложение в браузере (например, `http://127.0.0.1:5500/#tailwind` или нажмите кнопку **«ЛАБОРАТОРИЯ TAILWIND»** в главном меню).
2. На странице лаборатории доступны:
   - **Вкладки уровней**: Все задания, Уровень 1, Уровень 2, Уровень 3, Уровень 4, Дизайн-система.
   - **Интерактивный переключатель темы**: переключение между Светлой и Тёмной темой (`.dark`) в реальном времени.
   - **Эмулятор ширины экрана (Mobile-First)**: кнопки быстрого переключения ширины (375px Мобильный, 768px Планшет, 100% Респонсив) для мгновенной проверки адаптивности.

## Выполненные задания по уровням

### Уровень 1: Начальный
- **Задание 1.1: Карточка профиля (`ProfileCard.js`)**
  - Круглый аватар 80x80px (`w-20 h-20 rounded-full object-cover`).
  - Имя, должность, био чайного мастера.
  - Кнопки «Подписаться» («Follow») и «Сообщение» («Message») с интерактивным состоянием.
  - Адаптивность: на мобильных — `w-full`, на десктопе — `sm:w-80` (320px).
  - Утилиты: `rounded-full`, `shadow`, `flex`, `space-y-*`, `gap-*`.
- **Задание 1.2: Навигационная панель (`TailwindNavbar.js`)**
  - Логотип слева, центрированное меню (Главная, Каталог, Церемонии, Контакты), кнопка «Войти» справа.
  - Мобильное бургер-меню **без единой строчки JS**: реализовано на чистом CSS через скрытый чекбокс с селектором `peer` и классами `hidden md:flex`, `peer-checked:flex`.
  - Утилиты: `sticky top-0`, `backdrop-blur`, `z-50`.
- **Задание 1.3: Сетка карточек товаров (`ProductGrid.js`)**
  - Сетка из 6 карточек аутентичного чая.
  - Квадратные изображения (`aspect-square`), название, цена, словесная кнопка «В корзину».
  - Адаптив: 1 колонка → 2 колонки → 4 колонки (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`).
  - Утилиты: `hover:scale-105`, `transition-all`.

### Уровень 2: Средний
- **Задание 2.1: Hero-секция с градиентом (`GradientHero.js`)**
  - Главный экран с градиентным текстом заголовка (`bg-clip-text text-transparent bg-gradient-to-r from-purple-500 via-pink-500 to-amber-300`).
  - Фоновое изображение с темным оверлеем (`backdrop-blur`).
  - Декоративные фоновые круги с эффектом размытия и анимацией пульсации: `blur-3xl`, `animate-pulse`.
  - Две кнопки: primary (градиентная) + outline (с полупрозрачным фоном).
- **Задание 2.2: Pricing-таблица (`PricingTable.js`)**
  - 3 тарифа подписки: Базовый (Basic), Мастерский (Pro), Клубный (Enterprise).
  - Pro-тариф выделен: бейдж «Popular (Популярный)», `ring-2 ring-indigo-500`, увеличение масштаба `lg:scale-105`.
  - Списки фич с разделителями `divide-y`, отступами `space-y-*` и векторными SVG-иконками (галочки и крестики, строго без смайлов).
  - Адаптив: вертикальный стек на смартфонах (`flex flex-col lg:flex-row`).
- **Задание 2.3: Sidebar + контент (`SidebarDashboard.js`)**
  - Фиксированный сайдбар шириной 256px (`w-64`, `fixed inset-y-0 left-0`, `overflow-y-auto`).
  - Основной контент справа (`lg:pl-64`).
  - Topbar с полем поиска и аватаром.
  - На мобильных сайдбар скрыт (`-translate-x-full`) и выезжает по кнопке гамбургера с затемняющим фоном.
- **Задание 2.4: Форма регистрации (`RegisterForm.js`)**
  - Поля: Email, пароль, подтверждение пароля, чекбокс согласия.
  - Валидация средствами CSS: `peer`, `peer-invalid:border-red-500`, `focus:ring-2`.
  - Индикатор надежности пароля: 4 цветные полоски прогресса.
  - Кнопка Submit с состоянием загрузки (`loading-state`), спиннером и `disabled:opacity-50`.

### Уровень 3: Продвинутый
- **Задание 3.1: Мессенджер (`MessengerChat.js`)**
  - Левая колонка: список диалогов с аватарами, превью сообщений и unread-бейдж.
  - Правая колонка: чат с сообщениями (свои — справа изумрудные, чужие — слева серые).
  - Поле ввода сообщения закреплено снизу: `sticky bottom-0`.
  - Стилизация скроллбаров через arbitrary values: `[&::-webkit-scrollbar]:w-2`, `[&::-webkit-scrollbar-thumb]:rounded-full`.
- **Задание 3.2: Kanban-доска (`KanbanBoard.js`)**
  - 3 колонки: К выполнению (To Do), В процессе (In Progress), Завершено (Done).
  - Карточки с тегами категорий, приоритетами, аватарами исполнителей и визуальным drag-handle (6 точек).
  - Счётчики задач в шапке каждой колонки.
  - Горизонтальный свайп/скролл на мобильных экранах: `overflow-x-auto snap-x snap-mandatory`, `min-w-[300px]`, `line-clamp-2`.
- **Задание 3.3: Комплексный лендинг (`TailwindLanding.js`)**
  - Полный комплект секций: Sticky Navbar, Hero c CTA, 3-колоночный блок преимуществ, Testimonials-карусель без JS (`snap-x`), Тарифы, FAQ-аккордеон на `<details class="group">` с анимацией `group-open:rotate-180`, 4-колоночный подвал.
  - Вынос повторяющихся стилей в `@apply` в файле `css/tailwind-custom.css`.
- **Задание 3.4: Dark Mode (`DarkModeToggle.js`)**
  - Поддержка темной темы через `darkMode: 'class'`.
  - Префиксы `dark:bg-slate-900`, `dark:text-slate-100`, плавные `transition-colors`.
  - Кнопка-переключатель с векторными SVG-иконками солнца и луны.

### Уровень 4: Экспертный (Tailwind 3.4+)
- **Задание 4.1: Дашборд аналитики (`AnalyticsDashboard.js`)**
  - 12-колоночная адаптивная сетка: `grid grid-cols-12 gap-6`, `col-span-*`.
  - 4 stat-карточки с трендами (+12%, +8%, -3%, +24%).
  - График динамики выручки: визуальная сетка столбцов с градиентами и тултипами при наведении (`group-hover`).
  - Таблица транзакций с поиском, фильтром по статусам и скроллбаром.
- **Задание 4.2: Многошаговая форма (`MultiStepForm.js`)**
  - Степпер с 4 шагами: Контакты → Доставка → Оплата → Подтверждение.
  - Атрибуты доступности: `aria-current="step"`, `aria-required`, `aria-invalid`.
  - Использование селекторов Tailwind v3.4+ `has-[:checked]:*` для карточек доставки и способов оплаты.
  - Селекторы `data-[state=*]:*` для индикации состояний шагов (active / completed / pending).
- **Задание 4.3: E-commerce каталог с фильтрами (`EcommerceCatalog.js`)**
  - Фильтры по категориям, тегам, слайдер цены и выпадающий список сортировки.
  - Использование **Container Queries (контейнерных запросов)**: обертка `@container` со стилями `@sm:grid-cols-2` и `@2xl:grid-cols-4`.
  - Мобильный выезжающий снизу ящик (drawer) через `translate-y-full` и `backdrop-blur-sm`.
  - Состояние загрузки со скелетонами: `animate-pulse`.
- **Задание 4.4: Дизайн-система на Tailwind (`DesignSystemShowcase.js`)**
  - Токены цветов бренда (`brand`, `tea`) и семантики (`success`, `danger`, `warning`, `info`).
  - Типографика: `.heading-1`, `.heading-2`, `.heading-3`, `.body-text`, `.caption-text`.
  - Кнопки: `.btn-tw-primary`, `.btn-tw-secondary`, `.btn-tw-outline`, `.btn-tw-ghost`, `.btn-tw-danger` в размерах `sm`, `md`, `lg`.
  - Поля ввода, чекбоксы, toggle-переключатели.
  - Бейджи (`.badge-tw-*`), алерты (`.alert-tw-*`), модальное окно.
  - Документация в формате интерактивного Storybook с кнопками копирования классов.

## Критерии оценки и гарантии качества

| Критерий | Реализация в проекте |
|---|---|
| **Адаптивность (320px–1920px+)** | Mobile-First подход: базовые стили для мобильных + медиа-запросы `sm:`, `md:`, `lg:`, `xl:`, `2xl:`. Встроен эмулятор разрешений 375px/768px/100%. |
| **Семантика** | Использованы теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<details>`, `<summary>`, `<aside>`, `<footer>`. |
| **Доступность** | Атрибуты `aria-*`, управление фокусом `focus-visible:ring-2`, поддержка скринридеров, высокий контраст текста. |
| **Чистота классов** | Использование `@layer components` и `@apply` в `css/tailwind-custom.css` без дублирования. |
| **Состояния компонентов** | `hover:`, `focus:`, `active:`, `disabled:`, `group-hover:`, `peer-invalid:`, `has-[:checked]:`, `animate-pulse`, `empty`. |
| **Анимации** | Плавные переходы `transition-all`, `duration-200`, `duration-300`, `ease-in-out`, `animate-pulse`. |
| **Zero Emojis** | Строго 0 смайликов и символов эмодзи: все иконки выполнены на чистых SVG-векторах или семантическом тексте. |
