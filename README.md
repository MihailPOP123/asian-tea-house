# ASIAN TEA HOUSE — Адаптация проекта на Vue.js (ДЕНЬ 5-6-7)

Проект адаптирован с верстки сайта **Asian Tea House** на стек **Vue.js 3** + **Bootstrap 4** с соблюдением всех требований технического задания.

---

## Выполненные требования

### 1. Главная страница и компонент загрузки Excel (ExcelUploader)
* **Ограничение формата**: Компонент принимает **только** файлы Excel (`.xlsx`, `.xls`).
* **Модальное окно ошибки (ErrorModal.js)**: При попытке загрузить файл любого другого формата (например, `.txt`, `.png`, `.pdf`) открывается модальное окно с деталями отклоненного файла (имя, MIME-тип, размер) и информацией о допустимых форматах.
* **Способы загрузки**:
  * Drag-and-Drop (перетаскивание файлов в интерактивную зону).
  * Классический выбор файла через системный диалог.
* **Парсинг и сохранение**:
  * Файл читается и парсится через библиотеку **SheetJS (xlsx)**.
  * Распознанные строки автоматически заносятся в таблицу сортов чая.
  * Исходный файл в формате Base64 переносится и сохраняется в **локальное хранилище** (`localStorage`).
  * Предусмотрена кнопка **«Скачать готовый шаблон Excel»** для быстрой демонстрации.

### 2. Авторизация, регистрация и восстановление пароля «из коробки» (AuthView)
* Полноценные формы:
  * **Вход** (с кнопками быстрого заполнения для тестирования).
  * **Регистрация** (с выбором роли: Клиент, Менеджер, Администратор).
  * **Восстановление пароля** (мгновенная смена пароля по email).
* **Готовые учетные записи по умолчанию**:
  * Администратор: `admin@tea.com` / пароль: `admin`
  * Менеджер: `user@tea.com` / пароль: `user`
* **Разграничение прав**: Доступ к добавлению, редактированию и удалению товаров предоставляется только авторизованным пользователям. Неавторизованные пользователи могут просматривать каталог в режиме чтения.

### 3. Страница отображения данных в виде таблицы (TableView)
* Стилизация с применением **Bootstrap 4** (адаптивная таблица, бейджи, кнопки, карточки).
* **Постраничная загрузка (Пагинация)**: Активна при количестве записей > 10 строк (в базе предустановлено 12 сортов чая).
* **Кнопка ленивой подгрузки (Lazy Load)**: Кнопка `Загрузить еще (+5 сортов, Lazy Load)` для плавной дозагрузки данных без перезагрузки страниц.
* **CRUD операции**:
  * Добавление новых сортов чая (`Добавить новый сорт`).
  * Редактирование существующих сортов (`Редактировать`).
  * Удаление сортов с подтверждением в модальном окне (`Удалить`).
  * Поиск, фильтрация по категориям и сортировка по цене/названию/остатку.
  * **Экспорт в Excel**: кнопка `Экспорт в Excel` формирует файл через надежный механизм Blob и автоматически скачивает таблицу на устройство.
* **Переиспользуемый компонент модального окна (TeaModal.js)**:
  * Один и тот же компонент модального окна переиспользуется как для добавления, так и для обновления данных.
* **Асинхронный обмен данными**:
  * Все методы работы с хранилищем (`TeaApiService`) возвращают `Promise` с симуляцией асинхронного сетевого обмена и отображением индикаторов загрузки и всплывающих уведомлений (`ToastNotification`).

### 4. Страница администратора Voyager (AdminView)
* Установлен и стилизован компонент **Voyager** в качестве административной панели проекта:
  * Фирменный темный сайдбар Voyager (`#222d32`), плашка профиля администратора, карточки статистики (Dimmer Widgets).
  * Сводка ключевых показателей: количество сортов чая, остаток на складе, количество записей аудита, количество файлов в хранилище.
  * Быстрый экспорт таблицы каталога в Excel (`Экспорт каталога в Excel`).
  * Раздел **«Пользователи и Роли»** с механизмом назначения ролей (Admin, Manager, User).
  * Раздел **BREAD-менеджера** структуры таблицы товаров.
* **Тестовые данные при установке не добавлялись**: панель работает только со спроектированными рабочими сущностями.

### 5. Выбранное задание: Задание 2 (История действий Log и сравнение состояний vue-json-compare)
* Реализована таблица **Log** (`LogsView.js`), ведущая непрерывную историю всех действий (создание, редактирование, удаление, импорт из Excel, авторизация) с фиксацией времени, пользователя и описания.
* В таблице предусмотрена кнопка **«Сравнить изменения»**, которая открывает модальное окно сравнения состояния объекта **до изменения** и **после изменения**:
  * Подсветка измененных, добавленных и удаленных полей.
  * Блоки форматированного JSON в стиле `vue-json-compare`.
* **Дополнительно (из Задания 3)**: Реализован модуль просмотра загруженных файлов в локальном хранилище (`FilesView.js`) с возможностью скачивания и удаления файлов.

## Структура проекта

```
vue_project/
├── index.html                      # Главная HTML-страница (точка входа Vue 3)
├── main.js                         # Корневой экземпляр Vue 3, маршрутизация и состояние
├── sample_tea_import.xlsx          # Готовый тестовый Excel-файл для импорта
├── test_invalid_file.txt           # Текстовый файл для проверки модального окна ошибки
├── css/
│   └── style.css                   # Стили Asian Tea House + Bootstrap 4 + Voyager
├── images/                         # Изображения чая, логотипы и баннеры
├── js/
│   ├── storage.js                  # Асинхронные сервисы API, хранилища, авторизации, экспорта и аудита
│   ├── Header.js                   # Экспорт компонента шапки
│   ├── components/
│   │   ├── AppHeader.js            # Навигационная панель и профиль пользователя
│   │   ├── ExcelUploader.js        # Drag-n-drop загрузчик Excel (.xlsx, .xls)
│   │   ├── ErrorModal.js           # Модальное окно ошибки неподходящего формата файла
│   │   ├── TeaModal.js             # Переиспользуемое модальное окно создания/редактирования
│   │   ├── CompareModal.js         # Компонент сравнения состояний объектов (vue-json-compare)
│   │   └── ToastNotification.js    # Всплывающие уведомления об асинхронных операциях
│   └── views/
│       ├── HomeView.js             # Главная страница с каталогом и загрузчиком Excel
│       ├── TableView.js            # Страница таблицы CRUD, пагинации, экспорта и Lazy Load
│       ├── LogsView.js             # Журнал действий и аудит (Задание 2)
│       ├── FilesView.js            # Просмотр файлов Excel в локальном хранилище
│       └── AdminView.js            # Админ-панель в стиле Voyager
└── vendor/
    ├── bootstrap.min.css           # Bootstrap 4.6.2
    ├── vue.global.prod.js          # Vue 3 Runtime
    └── xlsx.full.min.js            # SheetJS Excel Parser
```
